# rg studio

Кроссплатформенный визуальный конструктор команд для
[ripgrep](https://github.com/BurntSushi/ripgrep), написанный на Rust и egui.
Приложение формирует команду в реальном времени, запускает ripgrep и показывает
результат в окне; команду также можно скопировать в буфер обмена.

## Возможности

- Поля основного поискового шаблона и пути.
- Визуальный regex-конструктор с литералами, классами, группами, альтернативами,
  якорями и квантификаторами.
- Проверка корректности собранного выражения в реальном времени.
- 95+ параметров ripgrep 15.2.0, распределённых по четырём вкладкам.
- Фильтр по названию и имени флага.
- Дополнительные аргументы для повторяемых и появившихся в новых версиях `rg` опций.
- Корректное экранирование шаблонов, путей и значений для текущей ОС.
- Живой предпросмотр: введите текст и сразу увидите найденные совпадения с подсветкой.
- Запуск ripgrep в фоне без shell, показ stdout, stderr и кода завершения в окне результатов.
- Запуск установленного ripgrep CLI без shell; результат показывается в отдельном окне.
- Контрастные светлая и тёмная темы, увеличенная типографика и адаптивные карточки параметров.
- Окно About с версией, Git SHA, временем сборки, Rust и target от vergen 10.

Предпросмотр тестового текста проверяет шаблон стандартным Rust regex-движком и
учитывает основные параметры поиска (регистр, фиксированные строки, многострочный
режим, Unicode, совпадение слова или строки). Для реального поиска используйте
**Run ripgrep**: приложение запускает CLI напрямую, не через shell. Дополнительные
аргументы разбираются как аргументы командной строки; shell-команды не выполняются.

## Архитектура

- `src/app.rs` хранит состояние приложения и собирает настройки предпросмотра.
- `src/ui.rs` отвечает за экран, диалоги, каталог параметров и генерацию команды.
- `src/theme.rs` задаёт общую палитру, контраст и типографику.
- `src/preview.rs` изолирует проверку regex и вычисление диапазонов совпадений.
- `src/search.rs` запускает ripgrep асинхронно и возвращает его результат в интерфейс.
- `src/command.rs`, `src/options.rs` и `src/regex_builder.rs` содержат модели команды,
  каталога опций и визуального конструктора regex.

## Требования и запуск

Установите [Rustup](https://rustup.rs/) и ripgrep 15.2.0, добавьте `rg` в `PATH`,
затем запустите приложение:

```powershell
rustup update stable
cargo run --release
```

Приложение сначала ищет `rg.exe` (или `rg` на Unix) рядом со своим бинарником,
затем — в `PATH`. Для переносной установки можно положить CLI рядом с
`rg-studio`; исходники ripgrep в репозиторий не включены. Проект использует
stable toolchain, заданный в `rust-toolchain.toml`.

## Quality Assurance

Перед изменениями обновите stable toolchain и установите аудит при необходимости:

```powershell
rustup update stable
cargo install cargo-audit --locked
```

Для теста запуска CLI установите ripgrep и проверьте, что `rg --version`
выполняется из `PATH` (или положите бинарник рядом с приложением).

```powershell
rg --version
```

Полный локальный цикл проверки:

```powershell
cargo fmt --all -- --check
cargo clippy --all-targets --all-features -- -D warnings
cargo test
cargo doc --no-deps
cargo audit
```

Публичные элементы документируются через `///`; предупреждения Clippy считаются
ошибками. `cargo audit` проверяет зафиксированное дерево из `Cargo.lock` по RustSec.
